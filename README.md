# DRE Paper Website

Static project page for **Is This 3D Asset Usable? Beyond the Beauty Render for Asset Curation**.

## Preview locally

```bash
python3 -m http.server 4173 --directory website
```

Open `http://localhost:4173`.

## Publish with GitHub Pages

The public project page is deployed from the repository root:

https://rbz-99.github.io/is-this-3d-asset-usable/

No build step or JavaScript dependencies are required. The test and training
dataset controls remain marked as coming soon until their public release.
